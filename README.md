# Farm Connect

Create a modern and responsive Farm to Dealer Marketplace web application using HTML, CSS, and JavaScript.

The application should have three separate user portals:

1. Farmer Portal

2. Dealer Portal

3. Driver Portal

Home Page:

- Attractive hero section with agricultural theme.

- App logo on the left side.

- App name in the center.

- Hamburger menu (three-line icon) on the right side.

The hamburger menu should contain:

- About Us

- Feedback

- Contact Us

- Privacy Policy

- Terms and Conditions

- Logout (visible only after login)

Authentication:

- Login with Google.

- Login with Mobile OTP (optional UI).

- Create Account option.

- Separate login pages for Farmer, Dealer, and Driver.

Farmer Dashboard Features:

- Upload Crops for Sale.

- Add Crop Name.

- Add Quantity.

- Add Price per Kg or Ton.

- Upload Crop Images.

- Select Harvest Date.

- Enter Farm Location.

- View Orders.

- Chat or Call Dealer.

- Payment Status.

- Transportation Request.

- AI Weather Alert card.

- Crop Price Prediction section (Future Feature).

- Profile Management.

Dealer Dashboard Features:

- Browse Available Crops.

- Search and Filter by Crop Name.

- Filter by Price.

- Filter by Quantity.

- Filter by Location.

- Buy Crops.

- Call Farmers.

- Book Drivers.

- View Order History.

- Subscription Plans.

- Payment Details.

- Delivery Tracking.

- Profile Management.

Driver Dashboard Features:

- View Transportation Requests.

- Accept or Reject Delivery Requests.

- Vehicle Details.

- Delivery History.

- Earnings Dashboard.

- Live Delivery Status.

- Call Farmers and Dealers.

- Profile Management.

Common Features:

- Google Login UI.

- Notifications.

- Secure Payment UI.

- Rating and Review System.

- Multi-language Support (Tamil and English).

- Responsive Design.

- Dark Mode Toggle.

- User Profile Editing.

- Dashboard Cards.

- Attractive Animations.

- Mobile Friendly UI.

Design Requirements:

- Use modern glassmorphism UI design.

- Use agricultural color themes (green, white, light brown).

- Smooth transitions and animations.

- Fully responsive for desktop and mobile.

- Use reusable components and clean code structure.

Technology Stack:

- HTML

- CSS

- JavaScript

Create separate HTML, CSS, and JavaScript files with well-organized and commented code.

The UI should look professional and similar to modern marketplace applications.
